# RE:FLOW 404 · 别把我排版掉

> **整张网页就是逃生地图。拖动真正的标题、按钮和弹窗，改变页面排版，在清理程序追来前救出一个即将被删除的 404 小生命。**
>
> 机制宣言：改排版 = 改地形；页面元素 = 物理实体；真正的 DOM 交互 = 游戏行动。

2026 WaytoAGI 1024 游戏赛道参赛作品。纯前端，打开即玩，无需登录。

## 玩法（10 秒学会）

- 一只叫**零四**的 404 小精灵会自动向右逃跑，你**不控制它的身体**
- 你是页面的**排版管理员**：按住网页模块右上角的 **≡ 手柄**，把真实的 `<h1>` `<button>` `<article>` 拖到断崖处——它们就是它的桥、弹板、台阶
- 拖动时世界 **0.22× 慢放**（追兵也一起慢，公平）；松手吸附到虚线锚点
- **按钮踩上去会弹起**；**面板可折叠**；第三幕一个 **LAYOUT 开关让整组模块真实重排**
- 白色清理波从左推进：被追上或坠入虚空 = 失败；跑到 SAVE 出口 = `404 → 200 OK`
- `SPACE` 暂停 · `R` 重试 · `M` 静音；支持触屏（44px 手柄 + 镜头跟随）

## 技术

- **真 DOM 是物理世界**：碰撞矩形全部来自 `getBoundingClientRect()` 实时测量——标题文字真的可以承重，这不是 Canvas 贴图伪装
- 纯 TypeScript 引擎（固定 60Hz 步进、抛物线自动跳跃规划、单向平台碰撞、携带物理）与渲染完全解耦
- Canvas 2D 只画角色 / 清理波 / 粒子 / 锚点幽灵（`pointer-events:none`）
- **运行时零依赖**，生产包 gzip ≈ 12KB
- 30/30 Vitest：物理不变量 + 三幕可解性证明（不改必败 / 参考解必胜 / 多路线）
