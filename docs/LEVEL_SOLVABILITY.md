物理验证覆盖（tests/physics.test.ts）：

- 单向平台：只允许下落穿过顶面落地；横向重叠 <8 不算落地；从下方上穿不撞头
- 土狼时间 90ms 存在性
- 抛物线求解数学正确（对称抛物线距离 ≈158.3）
- 目标过高 / 超最大跳距 → 不可达
- 弹跳 0.5s 冷却（冷却内作实体平台）
- 拖拽全局 0.22× 慢放；合法锚点释放计 1 edit、原槽/取消不计
- 清理线命中只结算一次；出口判定优先于清理
- 坠入虚空 → FAIL(fall)
- 平台携带（拖动中的平台带角色走，±120/步限幅）
- 面板折叠高度真实变化；网格重排 0.26s 引擎内插值动画
- 同输入同结果（确定性轨迹哈希一致）

## 调参记录（假设 → 改动 → 验证）

1. **假设**：初始 edgeLookahead=38 贴近规格。**观察**：英雄提前 38 单位起跳，弹跳射程不足，参考解全灭。**改动**：edgeLookahead=14。**结果**：三幕参考解全绿 ✓
2. **假设**：犹豫窗口 0.28s（规格值）。**观察**：真人/自动化均来不及拖拽。**改动**：0.45s。**结果**：仍紧张但可反应，关卡测试不受影响 ✓
3. **假设**：CSS transition 驱动第三幕重排。**观察**：后台标签页 left/top transition 冻结，测量把物理覆写回旧布局。**改动**：重排动画改引擎内插值（0.26s ease-expo），DOM 同步展示。**结果**：后台/前台一致 ✓
