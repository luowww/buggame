## 本版的设计选择

核心问题从“在什么时候切布局”改为“发生了什么、哪里第一次出错、改变什么会让世界恢复”。玩家不输入任意代码，也不回答选择题。编辑器只允许有限领域操作；相同编辑可能造成循环、漏站或归档失败，这些结果会由模拟执行产生。

Q-01 允许 `EXIT → DELETE → ARCHIVE` 和 `EXIT → ARCHIVE → DELETE` 两种顺序。DS-01 接受满足可达、无环、支线终止条件的实际线路，不检查某个按钮是否被点击。默认最小修复是 A.next=B，额外改动可得到另一条有效线路 A→C→B→END。

画面采用冷黑、钛白、琥珀与错误朱红，修复后薄荷绿进入轨道与灯光。建筑立面、雨、水、角色、列车与音轨均为程序化资产。模型追求统一、可读的低多边形身份；角色概念卡是独立的 AI 设计展示，并未冒充运行模型。

首章是明确的港区，不以背景楼群声称实现了 280×220m 无边界开放世界。主线是港口 → 维修桥 → 高架 → 列车返航；旁侧有通向核心观景台的两级坡道和 B 站检修步道。远景交通层用于城市尺度，不对外宣称全部可达。

## 发布后仍需要的工作

当前已完成可玩的首章与基础发布工程。要达到长期商业上线，仍需组织独立玩家试玩，验证谜题理解、探索密度与愿意复玩的原因；补齐安卓及 iOS 真机的性能和输入测试；再按反馈扩充关卡内容。八城、跨城回归、敌人与完整剧情属于后续开发，不能用一个首章的测试结果代替验收。
