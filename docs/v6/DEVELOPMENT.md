# V6 · 开发与工程说明

玩家图文玩法见[仓库首页](../../README.md)。本文中的代码路径均相对仓库根目录。

V6 指针港首章。真正的三维浏览器探索与因果修复游戏，基于用户提供的 V6 设计包重新实现。当前是完整可玩首章，尚未达到八主城完整版的内容规模。

你是零号，一个没有身份记录的城市残留体。MIRA 的女儿还在 B 站等待，列车却一直把那里跳过。你通过观察、扫描、改写有限的因果规则和重放验证，将她接回世界。

## 启动与构建

使用 Node.js 24 或更高版本。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5386
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5387
```

开发入口 `http://127.0.0.1:5386/`。生产入口是 `dist/index.html`，将整个 `dist/` 部署到支持 HTTPS 的静态托管服务即可。网页必须通过 HTTP(S) 访问，不能双击 HTML 以 `file://` 运行模块脚本。

正式构建不包含开发传送/模拟钩子。`window.__REFLOW__.snapshot()` 是只读诊断；`?perf=1` 显示实时测量的帧率、帧时和绘制量，不是预填数值。

## 已完成的完整一局

1. 进入真实 3D 指针港，移动、冲刺、跳跃、转动相机，找到 MIRA，取得因果织针。
2. **Q-01 事件失序**：扫描提前删除的站台；拖动事件顺序；分别验证普通和慢速旅客。失败提供可复现反例；正确排序展开有碰撞的维修桥。
3. 沿维修桥和坡道进入高架层。旁侧还可探索上层核心观景台，或步行前往失联的 B 站。
4. **DS-01 失联线路**：扫描实际遍历 `A → C → END`；拖动三维节点连线，或用键盘可聚焦的节点控件修改 `next`。实验可造成自环、漏站，均由独立模拟器判定。
5. 回归通过才提交线路。实体轨道、承重区域、车站招牌、城市窗灯、NPC 和列车停靠状态一起恢复。列车回放绑定同一 `runId` 的访问日志。
6. 在 A 站登车，经过恢复的车站，抵达 END 结算。可以留下自由探索、复制修复记录或重新开始。

两种有效事件排序都会通过。线路也不硬编码唯一答案：只要保持全部站点唯一可达、无环，且 B 站支线正常到达终点，其他有效线路同样会被认可。返航读取实际提交的路线。

## 工程结构

- `src/game/domain.ts`：纯 TypeScript 领域模拟、不可变事件日志、断言、补丁事务、版本化存档校验。
- `src/game/physics.ts`：60Hz 运动、跳跃缓冲、土狼时间、矩形承重面、斜坡、障碍和安全复位。适用于当前人工设计的场景，尚非通用物理引擎。
- `src/game/world.ts`：确定性模块城市、实例化楼体、原创建筑纹理、程序角色、实体轨道、列车、降雨与水面。
- `src/game/view.ts`：Three.js WebGL2 渲染、镜头插值、防遮挡与世界坐标投影。PC、窄窗口、手机竖屏具有不同的调试构图。
- `src/game/input.ts`：键盘、鼠标、摇杆和 Pointer Events。
- `src/game/audio.ts`：用户手势解锁的原创 Web Audio 编曲与反馈，默认静音。
- `src/game/main.ts`：任务状态、工作台、反例报告、演出、设置、暂停与结算。
- `public/character-card.html`：主角概念设定卡，明确区分 AI 概念图与实机模型。
- `tests/v6.test.ts`：新规则、事务、存档和碰撞测试；旧版 18 个测试仍保留。
- `qa/viewport.html`：本地响应式验收画框，不纳入正式构建。

采用 Three.js 直接管理渲染，不引入 React 的逐帧状态更新。重复楼体使用 [InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html)。角色碰撞选用文档允许的轻量 kinematic controller，任务模拟与视觉帧率独立。

## 存档与隐私

游戏不接入账号、分析服务或外部 AI API。进度和设置只保存在当前浏览器的 `localStorage`；无法使用存储时仍可游玩。继续游戏会回到已完成任务对应的安全检查点，尚未提交的编辑草案会被舍弃，证据保留。清除浏览器站点数据会丢失本地存档。Sites 试玩地址的访问范围由托管权限单独控制。
